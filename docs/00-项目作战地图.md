# 项目作战地图（总纲）

> 项目名：**Python 版智能分析 AI 助手**
> 目标：用 Python 生态复刻并**超越**那个 Java 版"鲸和 AI 助手"项目
> 定位：企业级开发全流程实战 + 教学，边做边沉淀可写进简历的工程能力

---

## 一、项目一句话定位

用户说一句"帮我分析上个月各科室患者完成情况"，系统自动：
**拆解目标 → 生成 SQL → 查数据库 → 反思纠错 → 输出可解释的分析报告**。

核心是 **Plan-and-Execute 智能分析 Agent + Text2SQL**。

| # | 能力 | 大白话 |

## 六、Bug Log 记录机制（简历核心资产）

> **每个 bug 都要记录**，格式统一，这是面试时最有说服力的东西。

### 记录模板

```markdown
### Bug #001 — [一句话标题]
- **发现时间**：2026-10-20
- **阶段**：阶段 1 / 小阶段 1.2
- **现象**：做了什么 → 出现什么错误
- **报错信息**：贴关键报错行
- **根因分析**：为什么会这样（技术原理）
- **解决方案**：怎么修的
- **经验教训**：以后怎么避免 / 可迁移的规律
```

### 记录位置
- 实时记录：`docs/bug-log.md`
- 每个 bug 都要编号，方便回顾和写简历时引用

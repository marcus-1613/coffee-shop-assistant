# 需求文档（PRD）— Python 版智能分析 AI 助手

> 版本：v1.0 | 日期：2026-10-20 | 状态：评审通过

---

## 一、背景与目标

### 背景
参考项目"鲸和 AI 助手"（Java/Spring Boot 实现）已具备完整的智能分析能力，但存在工程化短板（手写状态机、几乎无测试、文档散）。本项目用 Python 生态（FastAPI + LangChain + LangGraph）重新实现并**超越**之。

### 目标
1. 功能对齐：复刻 Java 项目的核心能力
2. 工程超越：更清晰的状态机、完整测试、更好的可维护性
3. 教学价值：作为企业级开发全流程的学习载体

## 三、核心功能需求

### F1：普通聊天
- 用户输入日常问题，系统直接回答，不升级为 Agent 流程
- 支持流式输出（SSE）

### F2：智能分析 Agent（Plan-and-Execute）
- 用户提出分析目标（如"分析上个月各科室患者完成情况"）
- 系统自动：规划 → 分步执行 → 反思 → 汇总报告
- 支持中途暂停，补充信息后继续

### F3：Text2SQL
- 自然语言 → SQL → 安全校验 → 执行 → 返回结果
- SQL 必须通过安全校验（只读、禁止危险操作）

### F4：状态机
- 任务状态：CREATED → PLANNING → RUNNING → SUCCESS/FAILED
- 决策类型：CONTINUE / RETRY / REPLAN / ASK_USER / FINALIZE

### F5：事件审计
- 每一步操作留痕（事件日志）
- 支持断线重连后增量补拉

### F6：安全边界
- Agent 只能通过 Text2SQL 引擎执行 SQL，不能绕过

## 五、验收标准（MVP）

1. 前端能对话，普通聊天流式返回 ✅
2. 能发起智能分析，Agent 自动拆解并输出报告 ✅
3. Text2SQL 能查演示数据库并返回结果 ✅
4. SQL 危险操作被拦截 ✅
5. 至少 50 个单元测试通过 ✅
